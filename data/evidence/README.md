# Evidence: real historical NVE warning

`flood_hamar_20230810_{no,en}.json` are byte-exact responses from the NVE Varsom flood API
(`.../flood/v1.0.10/api/Warning/Municipality/3403/1/2023-08-10/2023-08-10`) for Hamar, orange level (3),
valid 2023-08-10. The `.metadata.json` files record URL, retrieval time (2026-10-28), HTTP headers and SHA-256.
We re-fetched the URL and confirmed the bytes are identical.

This is a **historical** warning, used for archived replay. It is not a current warning.
The Norwegian and English official texts differ materially, so English is never treated as a translation reference.
